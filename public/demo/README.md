# Maple Street Kitchen synthetic demo images

These 18 JPEG files were generated with OpenAI image generation on August 27, 2026 for the public FieldProof demo in the OpenAI WebMCP Challenge.

The sequence shows one fictional residential kitchen over three fictional workdays. It contains no client record, real address, known person, or real job-site fact. Each image began with a prompt for a realistic contractor phone photo. Later images used the prior synthetic image as a reference so the room and cabinet work stayed consistent.

## Generation prompt set

Each prompt used the image-generation category `photorealistic-natural` for the first image or `precise-object-edit` for the continuing sequence. The shared instructions required a realistic landscape contractor phone photo, ordinary daylight, the same fictional kitchen, no people, no faces, no address, no paperwork, no logos, no text, and no watermark. The generated PNG outputs were resized and center-cropped with Sharp, saved as 960 by 720 JPEGs, stripped of source metadata, and checked in one contact sheet. FieldProof stores each JPEG through the same photo-check path used for a normal capture and computes a fresh SHA-256 hash from its saved bytes.
